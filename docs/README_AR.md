# THE_EMPIRE — شرح المشروع بالعربية

**المطور:** Shams Samara  
**النوع:** مشروع بحثي/تعليمي لتجارب TCP وTLS 1.3 وإدارة الجلسات في مختبر مصرح به.

## فكرة المشروع

THE_EMPIRE برنامج Python يجمع بين عميل وخادم TCP، ودعم TLS 1.3، والتبادل ثنائي الاتجاه، وبروتوكول رسائل يعتمد على ترويسة طول من 4 بايت، وإدارة جلسات اتصال متعددة. ويحتوي كذلك على وظائف نقل الملفات وبعض قدرات التحكم البعيد التي يجب حصر استخدامها في أنظمة المختبر التي تملكها أو حصلت على موافقة صريحة لتجربتها.

## ما الذي توثّقه الصور؟

1. **Kali Linux:** نجاح إنشاء اتصال TLS 1.3 مع خادم المختبر على Windows، وعرض جلسة تفاعلية بالمعرّف 1.
2. **Windows:** ظهور مستمع TCP، وقبول الاتصال الوارد، وإنشاء شهادة TLS ذاتية التوقيع.
3. **نقل الملفات:** تنفيذ alias باسم `ls` على Windows، وتنزيل ملف اختبار بحجم 15 بايت، مع عرض تجزئة SHA-256.
4. **مشاركات Windows:** عرض أسماء المشاركات مثل `C$` و`ADMIN$`. هذه النتيجة لا تثبت إمكانية الوصول إلى تلك المشاركات أو امتلاك صلاحيات إدارية.

## الميزات

- إنشاء اتصال TCP Client/Server.
- دعم TLS 1.3 افتراضيًا في مسارات الاتصال المدعومة.
- نقل بيانات ثنائي الاتجاه.
- وضع RAW دون تأطير تطبيق، ووضع آخر يرسل رسائل مؤطرة باستخدام JSON.
- إدارة جلسات الاتصال ومعرّفاتها وحالاتها.
- نقل الملفات وحساب SHA-256 ضمن مسارات نقل مدعومة.
- أوامر واجهة مناسبة لـWindows وLinux.
- سجل اختياري بصيغة JSONL.

## مثال آمن للتجربة المحلية

على Terminal أول:

```bash
python THE_EMPIRE.py --listen --target 127.0.0.1 --port 5555
```

وعلى Terminal ثانٍ:

```bash
python THE_EMPIRE.py --target 127.0.0.1 --port 5555
```

هذا المثال يختبر وضع Echo على الجهاز نفسه، دون إتاحة واجهة أوامر للنظام عبر الشبكة.

لعرض جميع الخيارات:

```bash
python THE_EMPIRE.py --help
```

## نموذج الاتصال

```text
Client (Kali/Windows)  <--- TCP + TLS 1.3 --->  Server (Windows/Linux)
              بروتوكول رسائل / أو تيار بيانات RAW
```

TLS يحمي البيانات أثناء النقل لكنه لا يعالج المصادقة تلقائيًا. في هذا الإصدار، التحقق من شهادة الطرف الآخر معطل، ولا توجد مصادقة قوية للـAgent، كما أن أحد مسارات تسليم الـAgent يعمل عبر HTTP غير مشفر. لذلك لا ينبغي اعتبار البرنامج آمنًا للنشر على الإنترنت أو للاستخدام في بيئة إنتاجية.
